5 August 2026

Cloudflare D1, schema memory, tunnels in-process

enginesassistantconnectionsbackup
  • Cloudflare D1 joins Postgres and SQLite: connect with an account id, database id and API token stored in the Keychain.
  • Schema memory. The assistant can store durable facts per connection with remember_fact and carries them between sessions.
  • Chat persistence. Conversations, including an undecided proposal, survive restarts.
  • SSH tunnels open in-process with your key files or ssh agent; no external ssh process.
  • SQL dump and restore for both engines from the connection menu, with Homebrew tool discovery.
  • The local model is only spawned when the assistant is turned on.
21 July 2026

The safety net, the agent, and the MCP server

safetyassistantmcpeditorpostgres
  • Change journal. Every committed grid edit recorded with its inverse SQL; one-click undo; 500 entries per connection.
  • Guardrails. UPDATE and DELETE without WHERE, TRUNCATE and DROP TABLE ask for confirmation in query tabs and the command bar.
  • Snapshots, FK navigation, column stats, semantic cell actions for URLs and emails.
  • Visual query builder with FK-suggested joins and saved specs. Relations view with an edge per foreign key.
  • taula-mcp. An MCP server over saved connections: seven tools, a read-only gate that rejects write keywords at any depth, writes behind TAULA_MCP_ALLOW_WRITES=1, row caps on every result.
  • Assistant sidebar (⌘L) on a local llama.cpp server: streaming tool loop with read tools and propose_write / propose_plan for anything that writes. Markdown replies with real result grids.
  • Ghost-text completion in the editor and inline AI edit (⌘I).
  • Data diff of two tables keyed on the primary key. Activity tab over pg_stat_activity with cancel and terminate.
  • Settings window and type-aware editors: date pickers, boolean toggles, UUID generation, JSON and hex inspectors, validation hints in the insert sheet.
  • Execution-graded eval corpus for the model's prompts, with a global local-AI toggle. Ghost completions measured at 87% on the corpus after a prompt fix.
17 July 2026

Daily-driver: the fast grid, the command bar, diffs and tunnels

grideditorconnectionsschema
  • AppKit grid. The data and result grids moved to NSTableView: any row count, infinite scroll, column widths remembered.
  • ⌘K command bar over tables, columns, objects, snippets, history, databases and actions, with SQL mode. Context-aware completion engine shared with the editor.
  • Editing without a primary key via rowid and ctid. Staged inserts and deletes with a full change-set preview before commit.
  • Multiple query tabs, syntax highlighting, autocomplete, run selection, several result sets per script, EXPLAIN visualizer, cancel running query.
  • SSH tunnels, structure editing with ALTER preview, indexes and foreign keys and triggers listed, CSV import with column mapping, JSON and blob editors.
  • Schema diff between connections, database-level operations, Objects tab for functions, sequences, enums and extensions, snippets, connection colors, backup and restore, the app bundle and DMG.
16 July 2026

first release

Common questions

How do I download Taula after buying it?

Your licence key arrives by email. Open your download page, paste the key, and the current build is one click away — along with every earlier version, in case you ever need to go back. There is no password to invent and no account to create; the key is the account.

I have lost my licence key.

Write to us from the address you bought with and we will send it again. If the key has been shared around and you would rather start clean, ask for a new one: the old key stops working the moment we issue the replacement.

Can I use one licence on several Macs?

Yes. One licence covers every Mac you own. The download page allows a generous number of downloads a day, which is there to make a key that has leaked onto the internet visible, not to count your machines. If you are setting up a lot of Macs at once and hit the ceiling, ask and we will lift it.

Which databases does Taula support?

PostgreSQL, SQLite and Cloudflare D1. MySQL and MariaDB are not supported and not promised. The databases page lists what works on each engine.

Is the assistant really local?

Yes. Taula starts a llama.cpp server on your Mac and downloads a small open model on first use. Your schema and your data stay on the machine. If you prefer a hosted model, add an Anthropic key in Settings and pick one there.

Can it write to my database without asking?

No. Grid edits are staged until you commit and review the SQL. The assistant returns writes as proposals you approve. Destructive statements in the query editor get a confirmation first. The MCP server is read-only unless you start it with writes enabled.

Does it need an account or send telemetry?

The app has no account, no sign-in and no analytics. Passwords live in the macOS Keychain. Connections, history and settings are plain JSON files in your Application Support folder.

macOS says the app is damaged or from an unidentified developer.

Make sure you downloaded the DMG from this site. If Gatekeeper still refuses it, right-click the app and choose Open once; after that it opens normally. If that does not work, write to us with the exact message.

The assistant says it cannot find llama-server.

Install it with brew install llama.cpp, or set the path to any llama-server binary in Settings. Taula checks the setting first, then Homebrew, then your PATH.

pg_dump is not found.

Install the Postgres client tools with Homebrew. Taula looks in the usual Homebrew locations for both Apple silicon and Intel Macs; a custom path can be set in Settings.

Where does Taula keep its files?

In ~/Library/Application Support/Taula: connections, query history, the change journal, snippets, chat transcripts and schema memory, all as JSON. Secrets are in the Keychain. The docs list each file.

What does the name mean?

Taula is Basque for table.

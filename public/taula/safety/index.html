ProductSafety net

Fast should not mean fragile.

A database client has four ways to write: the grid, the query editor, the assistant and an external agent. Taula puts something between you and the database on every one of them, and keeps a record of what went through.

Guardrails

Production looks like production.

Give a connection a color and the window carries a tint bar in that color, the session tab shows a dot, and you stop confusing staging with the real thing. Mark a connection as production and destructive statements get an extra warning that names it.

  • Destructive SQL asks first. An UPDATE or DELETE with no WHERE clause, TRUNCATE, DROP TABLE, in query tabs and the command bar alike.
  • Structure changes are previewed. Every ALTER from the Structure tab is shown before it runs.
  • Imports are transactional. A CSV import runs in one transaction and rolls back on the first bad row.
Journal and snapshots

Undo, and a copy for when undo is not enough.

The change journal records every committed grid edit with the SQL that reverses it, 500 entries per connection. Undo any entry with one click, or copy the inverse statement to hand to someone else.

Before a change you are unsure about, snapshot the table: one click runs CREATE TABLE snapshot_… AS SELECT * on the same connection. It is crude, it is fast, and it has saved more afternoons than any feature with a nicer name.

Diff

Find the drift before it finds you.

Two databases that should match rarely do. Taula compares them at the schema level and at the row level, across connections and across engines.

Schema diff

Tables, columns, indexes and foreign keys between any two connections or databases, as a color-coded, directional report. Compares Postgres to SQLite if you ask it to, by treating both as one flat schema.

Data diff

Row-by-row comparison of two tables, keyed on the primary key: added, removed and changed rows, with the changed columns highlighted.

Backup

PG · SQLite

pg_dump -Fc for Postgres, .dump for SQLite, with your Homebrew tools found automatically and the password passed through the environment, never the command line.

Restore

PG · SQLite

pg_restore --clean, or replaying a SQLite dump, from the same menu.

Generating sync SQL from a data diff is the next item on the list. Diffing is half the job; the other half is coming.

Privacy

Nothing leaves your Mac unless you ask.

No sign-in, no analytics, no crash reporter. Passwords, SSH passphrases and API tokens live in the macOS Keychain. Connections, history, journal and settings are plain JSON in Application Support, readable with any editor.

The assistant runs on a local model by default. The only way data leaves the machine is a connection you configured, or a hosted model you chose to add a key for.
